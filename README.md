# tapd-openapi

TAPD OpenAPI 操作：需求、缺陷、任务、迭代、Wiki、评论、工时与附件。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/tapd-openapi#v1.0.2 --skill tapd-openapi
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill tapd-openapi
```

## 内容

技能正文在 `skills/tapd-openapi/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/tapd-openapi/payload/`，不要反向同步。版本以 git tag 为准。
